小橘推送「本机命令」用到的开源组件
==================================

ios_system 和命令框架（files、text、shell、awk、tar、curl_ios、dash）
  https://github.com/holzschu/ios_system  BSD 3-Clause License, Copyright (c) 2018, Nicolas Holzschuch
  其中的命令来自 Apple 开源的 BSD 命令（file_cmds、text_cmds、shell_cmds），BSD 许可证；
  awk：The One True Awk（Lucent 许可证）；dash：BSD 许可证；curl：curl 许可证（MIT 类）。
lg2（git）
  https://github.com/holzschu/libgit2  libgit2：GPLv2 + linking exception；examples（lg2 命令本身）：CC0
OpenSSL 1.1.1w
  https://github.com/holzschu/openssl-apple  OpenSSL License / SSLeay License
  This product includes software developed by the OpenSSL Project for use in the OpenSSL Toolkit (http://www.openssl.org/)
libssh2 1.11.0
  https://github.com/holzschu/libssh2-apple  BSD 3-Clause License
Python 3.13（python3 命令）
  CPython：https://www.python.org  Python Software Foundation License Version 2
  iOS 版打包：https://github.com/beeware/Python-Apple-support  BSD 3-Clause License, Copyright (c) Russell Keith-Magee
  其中带的 OpenSSL 3、libffi、XZ、bzip2、mpdecimal 各自的许可证见 https://docs.python.org/3/license.html
cacert.pem
  Mozilla CA 证书包（来自 a-Shell 仓库），MPL 2.0
